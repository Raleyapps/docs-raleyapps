Everything configurable, requested, or stored by Raley Favourites for Jira, on one page. Current as of Cloud version 2.1.0.

## Settings

Raley Favourites has no documented settings screen and no documented admin configuration. Install it, then star work items; no setup step sits between the two in any published material. If a future version adds configuration, this section will list it.

## Permissions and scopes

The app requests 3 permissions, the smallest footprint of the 5 Raley apps. The canonical per-permission list, with what each one is used for, lives on the [application scopes page](/policies/Application-scopes#raley-favourites-for-jira); the Marketplace listing's Privacy & Security tab always shows the list for the latest version.

## Fields

The app creates no custom fields and writes nothing to your work items. Per the published scope justification, no work item is updated or modified in any way.

## Data storage

| Item | Value |
| --- | --- |
| What is stored | The numeric IDs of the work items you star |
| Where | Atlassian's app storage service |
| What leaves Atlassian | Nothing |
| Platform | Atlassian Forge |

Hosting, encryption, and GDPR details for all Raley apps live in the [data security and privacy statement](/policies/data-security-and-privacy).

## API

No API is documented for Raley Favourites, and no REST endpoints are documented for reading or writing your favourites list. Need programmatic access? Tell us via the [support page](/support) so we can gauge demand.
