This page covers the day-to-day tasks in Raley Favourites for Jira. First time using the app? Start with [getting started](/apps/raley-favorites/getting-started) instead.

## Add a work item to your favourites

1. Open the work item.
2. Select the more actions menu (**...**).
3. Select **Toggle favourite**.

The work item joins your list. Starring changes nothing on the work item itself and nothing in anyone else's view.

## Open your favourites list

1. Open a project.
2. In the project sidebar, select **Apps**, then **Favourites** under **Your apps**.

## Find a work item in a long list

Use the inline search in the favourites list to filter it.

## Remove a work item from your favourites

1. Open the work item.
2. Select the more actions menu (**...**).
3. Select **Toggle favourite** again.

The same action adds and removes: starred becomes unstarred. The work item itself is untouched.

## Result

Your list contains exactly the work items you have starred and not yet unstarred. Something off? See [troubleshooting](/apps/raley-favorites/troubleshooting).
