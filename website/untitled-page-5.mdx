By the end of this page you will have starred a work item (issue) and opened your favourites list in the project sidebar. Plan for about 5 minutes.

## Before you start

You need:

- A Jira Cloud site with [Raley Favourites for Jira](https://marketplace.atlassian.com/apps/1220204/raley-favourites-for-jira?hosting=cloud&ref=docs.raleyapps.com&utm_source=docs&utm_medium=productdocs&utm_campaign=raley-favorites-getting-started&utm_content=raley-favourites) installed. Not installed yet? Follow [Install your app](/apps/Get-started-with-RaleyApps#install-your-app); site admin permission is required for that step, and the rest of this page is not.
- Any work item you can open. Any project, any type.

## Step 1: star a work item

1. Open a work item you use often.
2. Select the more actions menu (**...**) on the work item.
3. Select **Toggle favourite**. It sits at the bottom of the menu, below entries like **Clone** and **Move**.

The work item is now on your favourites list. Nothing on the work item itself changes, and nobody else's view of it changes either.

## Step 2: open your favourites list

1. Open a project.
2. In the project sidebar, select **Apps**.
3. Under **Your apps**, select **Favourites**.

Your list opens, and the work item you starred in step 1 is on it. That is the success state: one starred work item, visible in the list.

## Step 3: use and prune the list

- Add more: repeat step 1 on any work item. Each one appears in the same list.
- Find one fast: when the list grows, use the inline search in the list.
- Remove one: open the work item and select **Toggle favourite** again. The same action adds and removes.
