## Raley Procurement for Jira & JSM

### v4.0.0 — April 2026

- **New:** Sales Quotes module — create, send, and track customer-facing quotes from within Jira
- **New:** Multi-level approval tiers — route POs through up to three approval stages based on department and spend threshold
- **New:** Jira dashboard widgets for PO spend and status reporting
- **New:** PDF customization — configure layout, logo, and columns for printed POs and quotes
- **Improved:** Goods receipt now supports partial delivery recording per order line
- **Improved:** Budget tracking now shows committed spend (approved POs not yet received) separately from actual spend

### v1.0.12-AC — June 2022

Security patch. See [Security Release Notes 2022](/apps/procurement/security-2022).

- Fixed: Unauthorized admin page access for JSM customer users
- Fixed: Missing authorization on multiple backend REST API endpoints

### v1.0.11-AC — December 2021

Security patch. See [Security Release Notes 2021](/apps/procurement/security-2021).

- Fixed: Log4Shell (CVE-2021-44228) vulnerability in the Purchase Orders AppServer — patched same day as disclosure

## Raley Emails Notifications

### v3.2.0 — March 2026

- **New:** Gmail OAuth integration — enables email threading via Message-ID tracking when using Gmail as the sending account
- **New:** Digest notifications — group multiple issue events into a single summary email on a configurable schedule
- **Improved:** CC and BCC recipients can now be set dynamically using Jira field values
- **Improved:** Approval and decline links now work directly from email for JSM service requests without requiring a Jira login

### v3.0.0 — October 2025

- **New:** SMTP integration — connect any SMTP-compatible mail server as the sending account
- **New:** Issue PDF snapshot attachment — attach a PDF of the Jira issue to outgoing notification emails
- **Changed:** Email template editor migrated to a new WYSIWYG interface — existing templates are preserved but may require layout review after upgrade

## Raley Intake Forms

### v2.1.0 — January 2026

- **New:** JIFF filters — control dropdown and multi-select field options based on project, issue type, or custom criteria
- **New:** Form-level rules — apply conditional logic at the form level, in addition to individual field rules
- **Improved:** Confluence Cloud add-on now uses `ACT_AS_USER` scope for more accurate issue attribution on submission

### v2.0.0 — July 2025

- **New:** WYSIWYG form builder with real-time preview
- **New:** Multi-language support — labels, help text, options, and buttons are fully internationalizable
- **New:** Custom CSS styling — apply your own stylesheet to match brand colors and fonts

## Raley Bookman
