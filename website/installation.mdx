Use this guide to install any of the 5 Raley apps on your Jira Cloud or Jira Service Management (JSM) Cloud site. The steps are identical for every app. Time: about 3 minutes.

Not sure which app you need? Read [Which app solves which problem](/choosing-an-app) first.

## Prerequisites

- A **Jira Cloud** or **JSM Cloud** site. Raley Bookman - Asset Reservation for JSM requires a JSM site.
- You are a **Jira admin** on that site. Only admins can install Marketplace apps.

## Option 1: install from inside Jira

1. In Jira's top navigation, select **Apps**, then **Explore more apps**.
2. Search for **Raley** and open your app in the results.
3. Select **Free trial**. Atlassian installs the app on your site, usually in under a minute.

## Option 2: install from the Marketplace website

1. Open [our vendor page on the Atlassian Marketplace](https://marketplace.atlassian.com/vendors/1212475/raleyapps-inversion-point?ref=docs.raleyapps.com&utm_source=docs&utm_medium=productdocs&utm_campaign=installation&utm_content=vendor-page) and select your app.
2. Select **Try it free**, then choose the Jira site to install it on. You must be an admin of that site.

Both options end in the same place: the app installed on your site with a free trial running. For how trials convert to subscriptions and how billing works, see [trials, licensing, and billing](/Get-started-with-RaleyApps#trials-licensing-and-billing).

## Verify the installation

Open the **Apps** menu in Jira's top navigation. Your Raley app appears in the list. Select it once to confirm it loads.

Done. Pick your first task from the [per-app list](/Get-started-with-RaleyApps#your-first-result-per-app).

## If something goes wrong

| Symptom | Cause | Fix |
| --- | --- | --- |
| The install button is greyed out or missing | You are not a Jira admin on this site | Ask a site admin to install the app, or to grant you admin permissions |
| The app does not appear in the Apps menu after install | The page has stale state, or the install has not finished | Refresh the browser; then check **Apps**, then **Manage apps**, where installed apps are listed |
| You want Bookman but cannot find where it runs | Bookman works through the JSM portal, and needs a JSM site | Confirm your site includes Jira Service Management, then see the [Bookman configuration guide](/apps/bookman/configuration) |

Still stuck? [Contact support](/support).

## Uninstall an app

1. In Jira, select **Apps**, then **Manage apps**.
2. Select the app, then **Unsubscribe** or **Uninstall**.

Billing stops with your subscription. For what happens to your data afterwards, see the [data security and privacy statement](/policies/data-security-and-privacy).
