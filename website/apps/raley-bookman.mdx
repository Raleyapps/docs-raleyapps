## Overview

Raley Bookman lets you display a specific subset of assets — represented by Jira tickets or JSM Assets — for bookings directly in the JSM customer portal. It gives your service desk team a simple, structured way to manage asset reservations without building custom solutions.

## Key Sections

### Application Scopes
Define which assets are available for booking and who can book them. Scopes let you control access per project or team.

### Asset Bookings Monitoring
View and manage all active and upcoming bookings from a central dashboard. Track availability and resolve conflicts before they happen.

### Bookman Configuration
Set up your asset catalog, booking rules, and availability windows. Configuration is done inside Jira project settings — no coding required.

### Making Bookings
End users submit booking requests through the JSM customer portal. Bookman handles availability checks and confirmation automatically.

### Features
- JQL-based asset filtering to show only relevant items
- Booking data stored securely (no private user data retained)
- 30+ day data backup retention

## Getting Started

1. Install Raley Bookman from the [Atlassian Marketplace](https://marketplace.atlassian.com)
2. Configure your application scope and asset catalog
3. Set your booking rules and availability windows
4. Enable the booking widget in your JSM customer portal
