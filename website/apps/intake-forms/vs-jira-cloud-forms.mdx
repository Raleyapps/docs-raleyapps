## Overview

Raley Intake Forms gives you full-power, externally shareable Jira intake forms — without the limits of native Jira Forms or the legacy Issue Collector.

## Feature Comparison

| Feature | Raley IntakeForms | Jira Cloud Forms | Jira Issue Collector |
|---|---|---|---|
| Unlimited form variants per project | Yes | Limited | No |
| Conditional logic / dynamic fields | Yes | Partial | No |
| Multi-language support | Yes | No | No |
| Custom validation rules | Yes | Limited | No |
| External publishing and embedding | Yes | No | Yes (limited) |
| Anonymous submissions with file attachments | Yes | No | No |
| WYSIWYG form designer | Yes | No | No |
| CSS branding and theming | Yes | No | No |
| Works on websites and intranets | Yes | No | Yes (limited) |
| Works in Confluence | Yes | No | No |
| Works for both Jira Software and JSM | Yes | Partial | Yes |
| Request source tracking | Yes | No | No |
| No JSM license required for external portals | Yes | No | No |

## Why It Matters

**Jira Cloud Forms** are built for internal teams, not external users. They're tied to Jira's screen model and can't be embedded outside of Jira.

**Jira Issue Collector** can be embedded externally but offers very limited field support, no conditional logic, no multi-language capability, and no custom styling.

**Raley IntakeForms** removes all of these limitations — giving you a professional, branded intake experience that connects directly to Jira without requiring requesters to have a Jira account.
