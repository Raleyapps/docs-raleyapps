## Overview

The Jira Issue Collector is a basic built-in tool for collecting external submissions. Raley Intake Forms goes significantly further in flexibility, usability, and customization. Here's how:

---

## 1. Visibility

Raley Intake Forms displays the full form directly on screen. Jira's Issue Collector hides behind a small trigger tab, which often confuses users who don't know it's there.

**Result:** More submissions, less user frustration.

---

## 2. Full Field Support

Intake Forms supports **all standard and custom Jira fields**, including:

- Default values
- Custom field rules
- Conditional field visibility (show/hide fields based on other inputs)

The Issue Collector only supports a limited, fixed set of fields.

---

## 3. Multi-Language Support

Build forms in any language. Field labels, help text, option values, and buttons are all fully internationalizable.

The Issue Collector offers no multi-language support.

---

## 4. No-Code Form Builder

Intake Forms includes a **WYSIWYG point-and-click editor** — no JavaScript knowledge required. You see the form exactly as users will see it while you build it.

The Issue Collector requires technical skills to customize beyond basic settings.

---

## 5. Custom Styling

Apply your own **CSS** to match your website's branding — colors, fonts, spacing, and layout. This builds user trust through consistent visual identity.

The Issue Collector has no CSS customization support.
