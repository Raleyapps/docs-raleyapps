## What Is Raley Intake Forms?

Raley Intake Forms lets you open your Jira to external users by allowing them to submit data into it through HTML web forms — without needing a Jira account.

This is ideal for:

- Corporate helpdesks that need external users (customers, partners, or non-IT staff) to raise tickets
- Teams that want a cleaner, branded intake experience instead of email-based ticket creation

## How It Works

Instead of routing requests through email, Intake Forms uses structured HTML forms that map directly to your Jira projects and issue types. This means cleaner data, less manual triage, and no missed information.

## Setup in 2 Steps

1. **Configure the form in Jira** _(admin task)_
   - Choose the target Jira project and issue type
   - Select which fields external users will fill in
   - Customize labels, help text, and rules
2. **Publish the form** _(can be done by anyone with access)_
   - Embed on your website or intranet
   - Or add to a Confluence page using the **Raley Intake Forms Viewer** plugin (available for Confluence Server and Cloud)

## Key Difference from Email

Unlike email-to-ticket integrations, Intake Forms binds directly to Jira's issue structure. Every submission creates a properly formatted issue with all the right fields filled in — no cleanup needed.
