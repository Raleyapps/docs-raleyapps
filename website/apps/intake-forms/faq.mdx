## Permissions

### What access permissions does Raley IntakeForms require?

The app requires three permission levels:

| Permission | Purpose |
|---|---|
| **READ** | Read Jira projects and issue configuration |
| **WRITE** | Create new Jira issues from form submissions |
| **ADMIN** | Poll meta information about Jira projects and issue types |

---

### What permissions are needed for the Confluence Cloud add-on?

The **Raley IntakeForms Viewer** add-on for Confluence requires:

| Permission | Purpose |
|---|---|
| **READ** | Read the contents of the Confluence page that contains the IntakeForms Viewer macro |
| **ACT_AS_USER** | Create Jira issues on behalf of the submitting user |
