The Asset Bookings Monitoring feature lets JSM agents and Jira users see all current reservations for an asset directly from the asset's Jira issue screen without switching to the customer portal or running a separate report.

- **JSM Agents**: can see reservations for all assets they have access to
- **Jira users**: any user with access to the Jira project that hosts the asset issues

<Frame>
  ![Image](/images/image.png)
</Frame>

## How to View Reservations

1. Open the Jira issue that represents the asset (e.g., the issue for "Meeting Room B")
2. Scroll to the **Raley Bookman** panel on the issue screen
3. The panel shows all current and upcoming reservations for that asset

Existing reservations are **highlighted in red** on the calendar.

## View Modes

| View | Description |
| --- | --- |
| **Calendar view** | Visual timeline of reserved and available time slots |
| **List view** | Tabular view with booking start/end times and links to the associated JSM booking tickets |

Switch between views using the toggle at the top of the Bookman panel.

## Use Cases

- **Conflict checking before approvals**: agents can confirm availability before approving a booking request
- **Asset utilization review**: see how frequently an asset is being booked
- **Finding the booking ticket**: list view provides direct links to the JSM tickets for each reservation
