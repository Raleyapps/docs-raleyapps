## Overview

Raley Procurement for Jira & JSM brings intake-to-procure experience into Jira and JSM — so your business team can create purchase requests, run the approvals, generate purchase orders, track deliveries and much more without switching tools.

## How It Works

Our app is an [Atlassian Forge](https://developer.atlassian.com/platform/forge/) cloud app, which lives next to your host product (Jira or JSM) and extends your work-item experience by serving a separate screen (IFrame), to capture, validate and run procurement-related process which is based on a Jira or a JSM ticket.

```text
Your team in Jira / JSM (submits procurement request as a work-item)
       ↓
Raley Procurement app (handles data intake, calculations, approvals routing, po-generation etc)
       ↓
Raley AppServer remotes (handles complex data processing)
       ↓
Jira/JSM: procurement workflow, user management, supplementary data intake.
```

**What this means in practice:**

- The app works with both: JSM and Jira
- Purchase request data is stored in Jira/JSM work-item as well as in Raley (line-item level data)
- All communication between the app and Atlassian uses SSL and FIT/JWT token authentication
- A purchase request is represented by a single work-item with your own custom workflow.
- On approval of purchase request it becomes a purchase order with PDF which stays in the same work-item
- Deliveries are tracked within the same work-item
- No user-private data is collected
- Data is retained for 60 days after uninstall, then permanently deleted

For the full data and privacy breakdown, see [Data Security and Privacy](/policies/data-security-and-privacy).

## What You Can Configure

### Suppliers & Products

- Add and manage your supplier database
- Import products in bulk via **CSV upload**
- Set up product catalogs with pricing and tax rules

### Financials

- Configure **multi-currency** support
- Define **tax rules** for different regions or categories
- Apply **discounts** at the order or line level
- Clear hand off to ERP after granting approval

### Order Customization

- Add **custom fields** to order lines
- Configure **contact persons** and delivery addresses per order
- Set up **approval workflows** for purchase requests

### Integrations

- Connect via **API** for external system integration

## Getting Started

1. Install Raley Procurement for Jira & JSM from the [Atlassian Marketplace](https://marketplace.atlassian.com)
2. Set up your approval workflow in Jira
3. Configure your suppliers and product catalog
4. Create your first purchase order
