## Overview

Raley Emails Notifications is available for both Jira Cloud and Jira Server/Data Center. The core functionality is the same, but some features differ between deployment types.

## HTML Restrictions on Cloud

> **Note:** In the cloud version, not all HTML tags are supported. Certain tags are stripped for XSS (cross-site scripting) security. If you need specific HTML formatting, test your template and check the rendered output in **Preview**.

## Events: Cloud vs Server

**Cloud-only events:** Issue Unassigned, Jira Comment Deleted, Issue Work Started/Stopped, Worklog operations

**Server-only events:** Jira Comment Deleted (server implementation), all Worklog operations

**Both:** Issue Created/Updated/Assigned/Transitioned/Commented/Resolved/Closed/Deleted, Project events, Version events
