## Overview

Raley Procurement and Quotation brings full procurement and quoting workflows into Jira and JSM — so your team can generate POs, manage suppliers, and track approvals without switching tools.

## How It Works

The app runs as an Atlassian Connect cloud add-on, which means it connects to your Jira instance through Atlassian's official app framework — no direct database access, no server-side code running inside your Jira.

```
Your team in Jira
       ↓
Raley Procurement app (Atlassian Connect)
       ↓
Raley AppServer (DigitalCloud + AWS, Amsterdam / USA)
       ↓
Jira REST API  ←→  Your Jira project data
```

**What this means in practice:**
- PO and quote data is stored on Raley's servers (DigitalCloud / AWS) — not inside Jira itself
- All communication between the app and Jira uses SSL and JWT token authentication
- Jira user permissions are checked for every action — the app cannot bypass your Jira project roles
- Data is retained for 60 days after uninstall, then permanently deleted

For the full data and privacy breakdown, see [Data Security and Privacy](/policies/data-security-and-privacy).

## What You Can Configure

### Suppliers & Products
- Add and manage your supplier database
- Import products in bulk via **CSV upload**
- Set up product catalogs with pricing and tax rules

### Financials
- Configure **multi-currency** support
- Define **tax rules** for different regions or categories
- Apply **discounts** at the order or line level

### Order Customization
- Add **custom fields** to order lines
- Configure **contact persons** and delivery addresses per order
- Set up **approval workflows** for purchase requests

### Integrations
- Connect via **API** for external system integration
- Review **security vulnerability release notes** (2021–2022)

## Getting Started

1. Install Raley Procurement and Quotation from the [Atlassian Marketplace](https://marketplace.atlassian.com)
2. Configure your suppliers and product catalog
3. Set up your approval workflow in Jira
4. Create your first purchase order or sales quote
