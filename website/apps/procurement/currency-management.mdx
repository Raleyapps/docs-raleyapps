## Overview

Raley Purchase Orders uses a **Default Currency** as the baseline for all budget calculations. When orders are placed in other currencies, exchange rates apply — but all budget statistics are displayed in the Default Currency.

<Warning>
You must set the Default Currency **before** creating any purchase orders. Once purchase orders exist in the system, the Default Currency cannot be changed.
</Warning>

## Default Setting

The system default is **USD**. Users with the **Finance** role can change this in the currency settings.

## How to Configure

1. Go to your Jira project configured for Purchase Orders
2. Open **Project Settings**
3. Navigate to **Purchase Orders – Settings**
4. Select the **Currency** tab
5. Set your Default Currency and save

## Notes

- Multi-currency support (different currencies per PO) is planned for a future release
- Only users with the Finance role can modify currency settings
