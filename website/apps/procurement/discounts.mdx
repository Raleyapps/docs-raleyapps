## Overview

Raley Purchase Orders supports discounts (also called rebates) applied at the **purchase order level** — meaning the discount applies to the entire order, not individual line items.

## When You Can Set a Discount

Rebates can only be configured when a purchase request has **INITIAL (Draft)** status. Once an order moves past draft, the discount is locked.

## How to Add a Discount

1. On the purchase order, click the **`...`** (dots) menu next to the **Add new order line** button
2. Select **Set Rebate**
3. In the popup, enter:
   - **Value** — the discount amount in the order currency
   - **Discount name** — a custom label (e.g., "Discount" or "Rebate")
4. Click **Save**

The gross amount of the purchase order will be recalculated automatically and the discount will appear on the order.

## Editing or Removing a Discount

While the order is still in draft status, you can reopen the rebate dialog at any time to change the value or name. To remove the discount entirely, set the **Value to 0**.

## Default Discount Name

Company administrators can configure a default discount name that pre-fills the label field. This is found in the **Company View** tab under **Default discount name**.
