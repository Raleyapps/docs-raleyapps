## Overview

By default, each purchase order shows the contact person and address defined in the selected **Department** settings. You can override these defaults on a per-order basis when needed.

## How to Set Custom Contact Information

1. On the purchase order, click the **`...`** (ellipsis) button next to **Add new order line**
2. Select **Set contact information**
3. Fill in the popup form with the custom contact person and address details
4. Click **Save**

The values you enter will override the department defaults for that specific purchase order only.

## Using Custom Data in PDF Templates

When generating PDF printouts, you can reference the custom contact details using these fields:

- `contactPerson` — outputs the contact person's name and details
- `address` — outputs the delivery address
