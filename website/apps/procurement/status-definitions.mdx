## Overview

Each purchase order moves through a defined set of statuses as it progresses from creation to approval and goods receipt.

## Statuses

| Status | Meaning |
| --- | --- |
| **Draft** | The order has been created and saved but not yet submitted. Order lines, discounts, and contact details can still be edited. |
| **Pending Approval** | The order has been submitted for approval. The assigned approver is notified and the order awaits their decision. |
| **Approved** | The approver has approved the order. It is ready to action and send to the supplier. |
| **Rejected** | The approver has declined the order. |

## After Approval

When ordered items arrive, recording goods receipt updates the order accordingly — including partial receipts. See [Goods Receipt](/apps/procurement/goods-receipt).
